# FoodSupply: поиск и сравнение поставщиков продуктов питания

Сервис помогает закупщику сети HoReCa или Retail (рестораны, доставка, магазины у дома) в **России и Казахстане**:

1. найти поставщиков продуктов, ингредиентов и упаковки по категории и городу;
2. собрать о них данные из нескольких источников, с пометкой, откуда взято каждое поле;
3. понять, с кем связаться первым: у каждого поставщика прозрачный балл 0–100, флаги рисков и сравнение;
4. сделать следующий шаг: письмо с запросом КП, статус в воронке, заметки команды, выгрузка в CSV.

## Что умеет

| Требование задания | Как реализовано |
|---|---|
| Поиск по категории товара | 11 категорий HoReCa (рыба, мясо, молочка, овощи, бакалея, японская кухня, соусы, заморозка, выпечка, упаковка, дистрибьюторы) и поиск по ключевым словам в ассортименте |
| Учёт города или региона | Город поставщика, регионы доставки («Москва и МО», «вся Россия», «Казахстан»); оценка «География» |
| Основная информация | Ассортимент, сайт, телефон, email, ИНН/БИН, адрес, данные реестра |
| Контакты, сайт, источник | Блок «Откуда данные»: источник и дата для каждого поля |
| Помощь в выборе | Балл с весами, которые пользователь задаёт сам, объяснение по каждому критерию, флаги рисков, сравнение 2–4 поставщиков, сводка по выдаче |
| Минимальный заказ | Сумма или партия (₽, ₸, кг, шт, коробов), сверяется с объёмом заказа пользователя |
| Примерная цена | Поле «Цены» (из сайта через LLM, вручную или из заметок); в запросе КП |
| Документы и сертификаты | Декларации ЕАЭС, ХАССП, ISO 22000, «Меркурий», халал; ссылки на реестры Росаккредитации и ФНС |
| Условия доставки | Порог бесплатной доставки, отсрочка платежа, описание доставки |
| Регион работы | Список регионов доставки |
| Комментарии и заметки | Заметки с автором и временем, статусы воронки (вход по имени) |

**Сверх задания:**
- **AI-ассистент.** Задача пишется своими словами («лосось для 12 суши-точек в СПб, 150 кг в неделю, с Меркурием»). Агент сам вызывает инструменты (поиск, реестр, чтение сайта, Яндекс.Карты) и возвращает шортлист с объяснением и ходом рассуждений.
- **Извлечение условий с сайта.** Сервис читает главную страницу и страницы о доставке, оплате, контактах и сертификатах, LLM переводит текст в структурированные поля.
- **Проверка юрлица каскадом.** Сначала DaData (РФ и КЗ), при ошибке или «не найдено» — Checko: статус, возраст компании, ОКВЭД, руководитель. Если ИНН не указан, его можно найти по названию.
- **Углублённая проверка (Checko).** Выручка и динамика, чистая прибыль, арбитражные дела, исполнительные производства ФССП. Влияет на «Надёжность» и даёт флаги риска.
- **Живой поиск по Яндекс.Картам.** Если в базе нет подходящих поставщиков, найденную организацию можно добавить в базу одной кнопкой, после чего она автоматически обогащается.
- **Письмо с запросом КП** с учётом категории: для рыбы, мяса и молочки письмо просит подтвердить работу в «Меркурии».
- **Воронка закупки:** новый → шортлист → запрос КП отправлен → КП получено → выбран или отклонён. Плюс выгрузка шортлиста в CSV для Excel.

## Как считается балл

`Балл = Σ(вес_i × оценка_i) / Σ весов × 100`. Каждый критерий оценивается от 0 до 1 и сопровождается текстовым объяснением. Веса пользователь меняет ползунками, и выдача сразу пересчитывается.

| Критерий | Вес по умолчанию | Логика |
|---|---|---|
| Соответствие | 25 | Профильная категория — 1, дистрибьютор широкого профиля — 0,6; плюс бонус за ключевые слова в ассортименте |
| География | 20 | Тот же город — 1, доставляет в город — 0,85, «вся страна» — 0,6, иначе 0,3, другая страна — 0,05 |
| Надёжность | 20 | По реестру: не действует — 0, возраст ≥ 10 лет — 1 … < 1 года — 0,15. Без реестра: ИНН на сайте — 0,5, ИНН нет — 0,35 |
| Документы | 15 | Декларации +0,4, ХАССП/ISO +0,3, «Меркурий» +0,3 (для рыбы, мяса и молочки), халал +0,1 |
| Коммерция | 15 | Минимальный заказ ≤ заказа пользователя — 0,85, иначе пропорционально; плюс бонусы за бесплатную доставку, отсрочку и известные цены |
| Полнота данных | 5 | Доля заполненных ключевых полей: меньше пробелов — меньше сюрпризов |

Флаги риска выводятся отдельно от балла: компания не действует или моложе года, нет ИНН, нет прямых контактов, нет «Меркурия» для животной продукции, минимальный заказ выше нужного, данные старше 180 дней.

## Данные

**Стартовая база: 93 реальных поставщика** (79 из РФ, 14 из КЗ) в Москве, СПб, Екатеринбурге, Новосибирске, Казани, Краснодаре, Алматы и других городах. Кандидатов находил поиском по категориям и городам, затем скриптом проверял их сайты 20.10.2026:
- ИНН и БИН (39 шт.), телефоны, email, минимальный заказ, порог бесплатной доставки, отсрочка и документы взяты **с сайтов самих поставщиков**;
- категории и описание ассортимента размечены вручную по сайту, это отмечено в источнике поля.

Почему комбинация источников, а не один:

| Источник | Что даёт | Доступ |
|---|---|---|
| Сайт поставщика + LLM | Условия: минимальный заказ, доставка, документы, цены | Бесплатно; LLM через OpenRouter (бесплатные модели) |
| DaData (ЕГРЮЛ, реестр РК) | Юрлицо: статус, возраст, ОКВЭД, адрес | Бесплатно до 10 000 запросов в сутки, РФ и КЗ; **первая ступень каскада** |
| Checko (бывш. Ofdata) | Финансы (ГИР БО), арбитраж, ФССП, контакты; запасной реестр РФ | Бесплатно 100 запросов в сутки; **вторая ступень каскада** и «углублённая проверка» |
| ФНС (egrul, pb.nalog), stat.gov.kz | Первоисточник | Официального API нет, из-за рубежа (HF) не отвечают, поэтому ручные ссылки |
| Яндекс Поиск по организациям | Новые поставщики в любом городе | Бесплатная квота; результаты показываются на Яндекс.Карте и хранятся только по явной кнопке «В базу» (условия API) |
| 2ГИС API | То же | Платный, поэтому не используется |
| B2B-площадки (Supl.biz, Pulscen, Agroserver) | Ассортимент | API нет, парсинг нарушает условия, поэтому не используются |
| Росаккредитация, «Меркурий» | Декларации, ветконтроль | Публичного API нет, поэтому в прототипе ссылки и ручная отметка |

## Архитектура

```
Браузер: Jinja + HTMX (без сборки фронтенда), дизайн-токены в app/static/theme.css
   │
FastAPI (app/main.py)
   ├── scoring.py    прозрачный скоринг, флаги, сводка по выдаче
   ├── agent.py      цикл «мысль → инструмент → результат», JSON-протокол, ≤ 6 шагов;
   │                 без ключа LLM — разбор запроса правилами, тот же поиск
   ├── service.py    обогащение с записью происхождения каждого поля (ручные правки не затираются)
   └── sources/
        ├── site.py    сайт → regex + LLM; защита от SSRF (запрет внутренних адресов, проверка редиректов)
        ├── dadata.py  реестр РФ (ИНН) и РК (БИН)
        └── yandex.py  Поиск по организациям
SQLite: suppliers (JSON-поля: категории, регионы, документы, источники, ответ реестра), notes, statuses
LLM: OpenRouter, список бесплатных моделей с автоматическим переключением при лимитах
```

**Почему такой стек.** Python, FastAPI и SQLite совпадают со стеком вакансии (Python, SQL, API, LLM, агенты) и разворачиваются одной командой. HTMX даёт живой интерфейс без отдельного фронтенд-проекта. Весь визуальный стиль задан CSS-токенами в одном файле, поэтому редизайн не требует правки шаблонов. Агент работает через JSON-протокол в тексте, а не через нативный вызов инструментов. Так он совместим с любой бесплатной моделью, и смена модели — это одна переменная окружения.

**Деградация без ключей.** Все интеграции необязательны. Без ключей работают поиск, скоринг, сравнение, воронка, извлечение условий регулярными выражениями и агент на правилах. Каждый ключ включает свою функцию.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # ключи по желанию
uvicorn app.main:app --reload
```

Тесты: `pip install pytest && pytest -q`.

### Деплой на Render (бесплатно)
1. Запушить репозиторий на GitHub.
2. render.com → **New → Blueprint** → выбрать репозиторий. Render прочитает `render.yaml` (Docker, план Free) и спросит значения ключей из `.env.example`.
3. Через 3–5 минут сервис доступен на `https://foodsupply-xxxx.onrender.com`. Для карты в кабинете Яндекса нужно добавить этот домен в ограничения по HTTP Referer у JS-ключа.

Бесплатный инстанс засыпает через 15 минут без посещений: первое открытие после паузы занимает 30–60 секунд.

### Деплой на Hugging Face Spaces (нужна подписка PRO)
Docker-Spaces на бесплатном CPU теперь доступны только с PRO.
```bash
pip install huggingface_hub
hf auth login                                   # токен с правом write
python scripts/deploy_hf.py <hf-user>/foodsupply
```
Скрипт создаёт Docker-Space, переносит ключи из `.env` в Secrets Space и загружает код.

База лежит в `/tmp` и при перезапуске пересоздаётся из `data/suppliers.json`. Для демо этого достаточно; для постоянного хранения заметок нужен Postgres или постоянный диск.

## Ограничения и развитие
- Цены публикуют редко. Дальше: разбор присланных прайсов (PDF, Excel) через LLM и история цен по позициям.
- Росаккредитация и «Меркурий» пока подключены ссылками. Дальше: официальная интеграция.
- Вход по имени без пароля сделан для демо. В проде: SSO компании и роли.
- Следующие шаги: рассылка запросов КП агентом и разбор ответов, рейтинг поставщиков по факту поставок (сроки, качество, возвраты), интеграция с учётной системой сети, MCP-сервер с теми же инструментами.
